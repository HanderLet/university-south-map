# Карта с зонами («Измененная карта») — дизайн

Дата: 2026-11-11
Статус: дизайн согласован в чате, ждёт ревью этого документа

## Цель

Статичный сайт-карта по образцу https://mirmll.github.io/UniverTutor/map, но на новой
карте и с навигацией по зонам. Пользователь выбирает зону, карта переносит его к ней,
подсвечивает контур и показывает важные точки зоны; по клику на точку открывается её
краткое описание. Справа сверху — переключатель дневной/ночной карты (☀️/🌙).

Успех: все 7 зон выбираются из меню и с карты, точки и описания открываются,
день/ночь переключается без сдвига зон и точек, сайт открывается двойным кликом по
`index.html` и без изменений работает на GitHub Pages, на телефоне (375 px) им удобно
пользоваться.

## Исходные материалы

- `img/map-day.webp` — дневная карта, 2000×1714.
- `img/map-night.webp` — ночная карта, 2000×1714. Совпадает с дневной пиксель в пиксель.
- `docs/superpowers/specs/zones-reference.webp` — разметка зон от заказчика (цветные контуры).
- Исходников в большем разрешении нет; используем эти.

## Подход

Leaflet 1.9.4 (CDN unpkg, как в примере), `L.CRS.Simple`, карта — один `L.imageOverlay`
на всю картинку. Без сборщиков, без сервера, без npm. Отвергнуты: нарезка на тайлы
(карта маленькая, выигрыша нет) и React/Vite (сборка мешает правке текстов).

## Структура файлов

```
index.html          — разметка страницы
css/style.css       — оформление (тёмный стиль, как в примере)
js/data.js          — зоны, контуры, точки и описания (правит заказчик)
js/app.js           — логика карты, меню, переключателя, редактора
img/map-day.webp
img/map-night.webp
```

`data.js` — обычный скрипт с глобальной константой `ZONES`, а не JSON: `fetch` JSON-файла
не работает при открытии через `file://`.

## Система координат

- Все координаты в `data.js` — пиксели картинки `[x, y]`, начало в левом верхнем углу,
  x: 0…2000, y: 0…1714.
- `app.js` переводит их в LatLng Leaflet: `[1714 - y, x]`. Заказчик с этим преобразованием
  не сталкивается.
- Границы карты `[[0, 0], [1714, 2000]]`; `maxBounds` = границы карты.
- `minZoom` — уровень, при котором карта целиком помещается в окно (вычисляется
  через `getBoundsZoom`); `maxZoom` = 1 (двукратное увеличение), чтобы картинка не
  превращалась в мыло.

## Формат данных (`js/data.js`)

```js
const ZONES = [
  {
    id: "state",                 // латиница, уникальный
    name: "Основной Штат",
    color: "#36c5f4",
    outline: [[x, y], ...],      // один контур
    // или outline: [[[x, y], ...], [[x, y], ...]] — внешний контур + вырезы
    points: [
      { name: "Мэрия", coords: [x, y], description: "Краткое описание..." }
    ]
  }
];
```

`description` — простой текст; переводы строк (`\n`) показываются как переносы.
HTML в описании не интерпретируется (вставляется как текст).

## Зоны

Контуры обводятся многоугольниками по `zones-reference.webp`.

| # | id         | Название                     | Цвет      | Примечание |
|---|------------|------------------------------|-----------|------------|
| 1 | `state`    | Основной Штат                | `#36c5f4` | северная/западная часть главного острова |
| 2 | `farm`     | Сельскохозяйственная зона    | `#f26a21` | поля и озеро между Округом и Штатом |
| 3 | `fbi`      | Остров ФБР                   | `#222222` | на ночной карте у контура тонкая светлая обводка-ореол |
| 4 | `county`   | Округ                        | `#fdd12f` | остров в горах внутри Заштатья |
| 5 | `rich`     | Богатый район                | `#7ac70c` | восточные кварталы + южный остров одним многоугольником, соединённым по мосту (как на разметке) |
| 6 | `race`     | Гоночная трасса              | `#6a2c91` | прямоугольник с трассой сверху |
| 7 | `outskirts`| Заштатье                     | `#e3172d` | внешняя красная рамка с вырезом по контуру Округа |

Мелкие островки вне контуров ни к одной зоне не относятся.

В каждой зоне 2–3 точки-заглушки с названиями вида «Точка 1 (заглушка)» и пустым
описанием; реальные точки и тексты заказчик добавит позже (сам через редактор или
прислав разметку).

## Поведение

### Начальный экран
- Карта целиком (`fitBounds`), без подсветки и без точек.
- Внизу горизонтальная лента из 7 карточек зон в порядке таблицы; у каждой карточки
  цветная полоска цвета зоны.
- Контуры зон на карте невидимы, но интерактивны: при наведении проступает контур
  (тонкая обводка цвета зоны) и подсказка с названием; клик выбирает зону.

### Выбор зоны (из ленты или кликом по карте)
1. `flyToBounds` по контуру зоны с отступами (учитывая высоту нижней ленты), ~1 с.
2. Контур подсвечен: обводка 3 px цвета зоны, заливка того же цвета с прозрачностью ~0.15.
   Остальные зоны неактивны (не реагируют на наведение).
3. На карте появляются маркеры только этой зоны (круглые, цвета зоны, со свечением,
   как в примере).
4. Лента заменяется на: кнопку «← Все зоны», затем карточки точек зоны.
5. Пока зона выбрана, другие зоны на карте не реагируют на наведение и клик; чтобы
   выбрать другую зону, нужно нажать «← Все зоны».

### Точка
- Клик по карточке точки: `setView` на точку с зумом `min(maxZoom, текущий + 1)`,
  затем открывается всплывающее окно.
- Клик по маркеру открывает то же окно.
- Окно: название цветом зоны и описание. Пустое описание → «Описание скоро появится».

### «← Все зоны»
Закрывает окно, убирает подсветку и маркеры, возвращает ленту зон, `flyToBounds`
к общему виду.

### Переключатель ☀️/🌙
- Круглая кнопка справа сверху (≥ 44×44 px). Показывает значок режима, на который
  переключит (днём — 🌙, ночью — ☀️).
- Меняет `src` у слоя карты и цвет фона за картой (день `#3c5d9d`, ночь `#0e152e` —
  взяты пипеткой с края картинок), чтобы края карты не выделялись.
- Выбор сохраняется в `localStorage` (чтение/запись в `try/catch`); по умолчанию день.
- Зоны, маркеры и открытое окно при переключении не сбрасываются.

### Режим редактора (`index.html?edit`)
- Плашка «Режим редактора» вверху слева (под кнопками зума).
- Клик по карте: показывает `[x, y]` в пикселях картинки (целые числа) и копирует строку
  `[x, y]` в буфер обмена; если копирование недоступно — просто показывает.
- При загрузке проверяет, что каждая точка лежит внутри контура своей зоны; нарушения
  выводятся списком в плашке и в `console.warn`.
- В обычном режиме ничего из этого не видно.

### Мобильные
- Лента листается свайпом, карточки не сжимаются.
- Всплывающее окно не шире `calc(100vw - 32px)`.
- Нет горизонтальной прокрутки страницы.

## Ошибки и крайние случаи
- Картинка карты не загрузилась → поверх карты сообщение «Не удалось загрузить карту».
- Зона без точек → в ленте только «← Все зоны» и надпись «Точек пока нет».
- Ошибки в `data.js` (нет `outline`, не тот формат `coords`) → зона/точка пропускается,
  предупреждение в консоли; остальной сайт работает.

## Проверка
Вручную в браузере (тестового фреймворка у статичного сайта нет):
- каждая из 7 зон: выбор из ленты и кликом по карте, подсветка, перелёт, маркеры;
- клик по карточке точки и по маркеру, пустое описание;
- «← Все зоны»;
- день/ночь: смена картинки и фона, сохранение после перезагрузки, нет сдвига точек;
- Заштатье подсвечивается без Округа;
- `?edit`: координаты при клике, предупреждение для точки вне зоны;
- ширина 375 px: лента, кнопки, окно;
- открытие через `file://` и через локальный HTTP-сервер.

## Вне рамок
- Поиск по точкам, фильтры, картинки в описаниях, несколько языков.
- Публикация на GitHub Pages (папка будет готова к выкладке, выкладывает заказчик).
