# Карта с зонами — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Статичный сайт-карта на Leaflet с 7 зонами, точками, описаниями, переключателем день/ночь и режимом редактора координат.

**Architecture:** Чистые функции (координаты, попадание в многоугольник, проверка данных) лежат в `js/geo.js` и тестируются через `node --test`. Данные зон — в `js/data.js` (глобальная `ZONES`). UI разбит на `app.js` (карта, зоны, точки), `theme.js` (день/ночь), `editor.js` (`?edit`). Всё подключается обычными `<script>`, без сборки.

**Tech Stack:** HTML/CSS/JS (ES2020, без модулей), Leaflet 1.9.4 с unpkg, Node 24 (`node --test`) для юнит-тестов, встроенный браузер + `python -m http.server` для проверки UI.

**Spec:** `docs/superpowers/specs/2026-11-11-zone-map-design.md` (+ `zones-reference.webp` рядом)

## Global Constraints

- Leaflet ровно `1.9.4`: `https://unpkg.com/leaflet@1.9.4/dist/leaflet.css` и `.../leaflet.js`.
- Картинки 2000×1714; координаты в данных — пиксели `[x, y]` от левого верхнего угла; в Leaflet `[1714 - y, x]`.
- `maxZoom` = 1; `minZoom` = зум, при котором карта целиком влезает в окно (`getBoundsZoom`), `zoomSnap` 0.25.
- Фон за картой: день `#3c5d9d`, ночь `#0e152e`. По умолчанию день. Ключ `localStorage`: `mapTheme` (`"day"`/`"night"`).
- Цвета зон: state `#36c5f4`, farm `#f26a21`, fbi `#222222`, county `#fdd12f`, rich `#7ac70c`, race `#6a2c91`, outskirts `#e3172d`.
- Тексты: «← Все зоны», «Описание скоро появится», «Точек пока нет», «Не удалось загрузить карту», «Режим редактора».
- Сайт обязан работать при открытии `index.html` через `file://` (никаких `fetch`, `type="module"`).
- Описания вставляются как текст (`textContent`), `\n` → перенос строки (CSS `white-space: pre-line`).
- Отклонение от спеки по структуре: вместо одного `app.js` — `geo.js`, `app.js`, `theme.js`, `editor.js` (по одной ответственности на файл); плюс `tests/`.

## Review Focus

1. Клик по морю или мелкому островку на общем виде → ничего не происходит, ошибок в консоли нет. (Задача 4)
2. Двойной клик по карточке зоны → зона остаётся выбранной (второй клик не попадает в появившуюся на том же месте «← Все зоны»). (Задача 4)
3. `localStorage` бросает исключение (приватный режим, заблокированные данные) → переключатель работает, тема просто не запоминается. (Задача 5)
4. В описании точки есть `<b>` или `<script>` → показывается как текст, не исполняется. (Задача 4)
5. Поворот телефона / изменение размера окна → `minZoom` пересчитывается, на общем виде карта снова вписана целиком. (Задача 3)

**Files:**

**Interfaces:**
- Produces (глобальный `MapGeo` в браузере, `module.exports` в Node — UMD-обёртка):
  - `IMG_W = 2000`, `IMG_H = 1714`
  - `toLatLng([x, y]) -> [lat, lng]` = `[IMG_H - y, x]`
  - `toPixel({lat, lng}) -> [x, y]` — округление до целых, обратное к `toLatLng`
  - `normalizeRings(outline) -> Array<Array<[x, y]>>` — одиночный контур `[[x,y],...]` → `[ring]`; контур с вырезами `[[[x,y],...], ...]` → как есть; иначе `null`
  - `pointInZone([x, y], outline) -> boolean` — внутри первого кольца и не внутри остальных (ray casting)
  - `validateZones(zones) -> { zones, warnings: string[] }` — выбрасывает зону без корректного `outline`/`id`/`name`, выбрасывает точку без `name` или с `coords`, не являющимися парой конечных чисел; на каждый выброс — строка в `warnings`
  - `findStrayPoints(zones) -> string[]` — строки вида `Зона «Округ»: точка «Точка 1 (заглушка)» вне контура`
