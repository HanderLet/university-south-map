# Карта RPM — зоны

Интерактивная карта с зонами, точками и переключателем день/ночь (☀️/🌙).

## Как открыть

Двойной клик по `index.html` — сайт работает без сервера.
Нужен интернет: библиотека Leaflet грузится с unpkg.com.

## Как править точки и описания

Все данные лежат в `js/data.js`: зоны, их контуры, точки и описания.

```js
{ name: "Мэрия", coords: [1180, 450], description: "Краткое описание" },
```

- `coords` — пиксели картинки `[x, y]` (x: 0–2000 слева направо, y: 0–1714 сверху вниз).
- Пустое `description` — на сайте будет «Описание скоро появится». Перенос строки — `\n`.

Чтобы узнать координаты, откройте `index.html?edit` и кликните по карте —
координаты появятся в панели слева и скопируются в буфер обмена. Там же
предупреждение, если какая-то точка оказалась вне своей зоны.

После правки обновите страницу с очисткой кэша (Ctrl+F5).

## Проверка данных (необязательно)

```
node --test tests/geo.test.js tests/data.test.js
```

## Выложить на GitHub Pages

Загрузите в репозиторий `index.html` и папки `css`, `js`, `img`,
затем Settings → Pages → Deploy from a branch → `main` / `root`.
