# Карта RPM — зоны

Интерактивная карта с зонами, точками и переключателем день/ночь (☀️/🌙).

## Как открыть

Двойной клик по `index.html` — сайт работает без сервера.
Нужен интернет: библиотека Leaflet грузится с unpkg.com.

## Как править точки и описания

Проще всего — в редакторе на сайте:

1. Откройте `index.html?edit`.
2. Выберите зону в ленте внизу.
3. Кликните по точке — появятся поля «Название» и «Описание». Точку можно
   перетащить мышкой или удалить кнопкой «Удалить точку».
4. Чтобы добавить точку, кликните по карте внутри выбранной зоны и нажмите
   «+ Добавить точку сюда».
5. Нажмите «Скачать data.js» и замените скачанным файлом `js/data.js`.

Правки в редакторе живут только до перезагрузки страницы — не забудьте скачать файл.

Можно править и вручную: все данные лежат в `js/data.js`.

```js
{ name: "Мэрия", coords: [1180, 450], description: "Краткое описание" },
```

- `coords` — пиксели `[x, y]` в системе 2000×1714 (x слева направо, y сверху вниз).
- Пустое `description` — на сайте будет «Описание скоро появится». Перенос строки — `
`.

После замены `data.js` обновите страницу с очисткой кэша (Ctrl+F5).

## Проверка данных (необязательно)

```
node --test tests/geo.test.js tests/data.test.js tests/datafile.test.js
```

## Выложить на GitHub Pages

Загрузите в репозиторий `index.html` и папки `css`, `js`, `img`,
затем Settings → Pages → Deploy from a branch → `main` / `root`.
